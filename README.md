# MA JIYU · Portfolio

A bilingual personal portfolio of machine learning, web engineering, games, creative coding and scientific computing.

**Website:** https://2273862959-sketch.github.io/

## Develop

Requires Node.js 22 or newer. No third-party build dependencies.

```sh
npm run build
npm run check
npm run dev
```

Edit `content.mjs` for project copy and evidence links, `public/style.css` for layout, and `scripts/build.mjs` for templates. GitHub Actions builds and publishes `dist` to GitHub Pages.
